# 🎨 KiddieHands Academy — Interactive Gesture Education Game

An interactive browser-based educational game for kids featuring **Alphabet Tracing**, **Jawi Letter Matching (ا ب ت)**, and **Visual Mathematics**, powered by **MediaPipe Hands** for touchless camera pinch-and-drop gestures (with full mouse/touch fallback).

## ✨ Features
- **🚀 Loading & Syllabus Selection:** Choose your control mode (Mouse/Touch vs. Camera Gestures) and select your learning syllabus.
- **🔤 ABC Tracing & Styles:** Trace dashed uppercase letters with multiple styles: Magic Pencil, Rainbow Brush, or Star Stamps!
- **🕌 Jawi (ا ب ت):** Match Rumi pronunciations (*Alif, Ba, Ta...*) by pinching/dragging the correct Jawi card into the target drop zone.
- **🔢 Math Pick & Drop:** Count visual fruit icons, pinch/drag the right number tile, and drop it in the box.
- **📷 Full-Screen Camera Gesture Mode:** Runs the camera in the background across the entire screen for natural hand pinch-and-drop mechanics.

## 🚀 How to Deploy on GitHub Pages
1. Create a new repository on [GitHub](https://github.com) (e.g., `kiddiehands-game`).
2. Upload `index.html` and `README.md` to the repository.
3. Go to **Settings** → **Pages**.
4. Under **Build and deployment** → **Branch**, select `main` and `/ (root)`, then click **Save**.
5. Open your live `https://<username>.github.io/<repo-name>/` URL (HTTPS is required by browsers to access the webcam).
